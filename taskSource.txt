Перед этим всем nginx, это все в докере.
Минимальное потребление ОЗУ, соответсвующий выбор технологий.

В начальном конфиге первичный url и первичный пароль для админа, root url этого всего.

Админ переходит по первичной ссылке, вводит первичный пароль, иначе ничего не доступно. Для него генерируются новые постоянные ссылка и пароль, старые больше не работают, с новыми доступно всё.

Админ может создавать нового юзера, указав юзернейм и сколько времени это доступно, для юзера генерируются первичные ссылка и первичный пароль.
Юзер должен перейти по ссылке, ввести пароль, для него сгенерируются постоянные ссылка и пароль, иначе ничего не доступно.

Админ может создавать пасты (raw text), указывать Title и каким конкретным юзерам (или всем) они доступны, удалять пасты.
При удалении пасты имеющим право просмотра юзерам показывается в тексте пасты [Данные удалены].

Юзеры могут постить пасты, доступные админу (больше никому), удалять не могут.

Юзер видит список паст в порядке возрастания времени.

Время конвертируется в UTC+0, при просмотре показывается в UTC+0 и в часовом поясе юзера.

Юзеру отображается, сколько паст появилось с момента его первого захода.
Устанавливаются куки при вводе постоянного пароля.
Пароль не может быть валиден при переходе по ссылке другого человека (т.е. ссылка - логин, пароль - пароль)
